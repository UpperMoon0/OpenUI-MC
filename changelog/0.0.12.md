# OpenUI MC 0.0.12

## Overflow safety

- Give `Card`, `Panel`, and `StyledBox` one protected child-content rectangle shared by layout, painting, and descendant hit-testing so clipped-away pixels are never interactive.
- Make rounded surfaces use a radius-safe rectangular content region, preventing low-padding descendants from painting over rounded border arcs or transparent corner pixels; safe geometry now clamps oversized/pill radii exactly like the renderer instead of over-reserving content space.
- Make `StyledBox` render its configured multi-pixel `borderWidth` and reserve the renderer-clamped effective border width in child layout/clipping.
- Keep Card's one-pixel focus/selection outline gutter stable across transient state changes so focusing or selecting a zero-padding card never reflows its child content.
- Keep `VStack`, `HStack`, and `Stack` non-clipping/non-scrollable by default; scrolling remains explicit through `Ui.scroll(...)`.
- Preserve elevated shadows outside the child clip and preserve dropdowns, popovers, tooltips, dialogs, toasts, and drag feedback as independent overlay roots.

## Diagnostics

- Add inspector/JVM-property development warnings for bounded non-scroll overflow without adding production measurement cost when diagnostics are disabled.
- Suppress overflow advice for constraint-managed/flex subtrees and `fillHeight()` sentinel measurements so the documented `column(header, scroll(body).flex())` pattern does not produce false warnings.
- Publish `LayoutDiagnostics` as an explicit `@PublicApi` development/tooling surface introduced in 0.0.12.

## Compatibility and verification

- Advance the primary released JVM ABI baseline from 0.0.9 to 0.0.11 while retaining the 0.0.7 legacy baseline.
- Add render-path regressions across 1.20.1, 1.21.1, and 26.1.2 for real scissor push/pop, nested intersection/restoration, protected content clips, explicit scrolling, and overlay escape behavior.
- Add regressions proving flexed explicit-scroll and direct `fillHeight()` layouts do not emit false overflow diagnostics.
- Refresh dependency, release, clipping, and custom-surface documentation for the current GitHub Packages/release workflow.
