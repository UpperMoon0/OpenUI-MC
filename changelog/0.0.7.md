# OpenUI MC 0.0.7

## Fixed

- Container screens no longer close when the inventory key is pressed; focused fields can type that key and Escape remains the close action.
- NeoForge 26.1.2 container chrome is extracted before vanilla slots so item models remain visible.
- NeoForge 26.1.2 dynamic container dimensions synchronize container bounds/viewport and outside-click calculation to prevent unintended carried-item drops.
- NeoForge 26.1.2 resource metadata now declares the correct resource pack format bounds (`[84, 0]`).
- Native text fields render without text shadows on the supported 1.21+ targets.

## Changed

- NeoForge 26.1.2 container screens support explicit and dynamically computed viewport dimensions (`containerWidth()` / `containerHeight()`) for wide responsive layouts.
