# OpenUI MC 0.0.3

## Fixed

- Added valid `pack.mcmeta` resource-pack metadata to every published loader artifact.
- Fixed Forge 1.20.1 reporting that the OpenUI jar could not produce a valid `ResourcePackInfo`.
- Published loader artifacts as standalone Maven dependencies without unresolved internal common-project dependencies in their generated POM files.

## Compatibility

- Uses the resource-pack format required by each supported Minecraft target: 15 for 1.20.1, 34 for 1.21.1, and 84 for 26.1.2.
- Consumers using a Maven-local development build should update to `0.0.3` so ForgeGradle resolves a new transformed dependency instead of reusing its cached `0.0.2` jar.
