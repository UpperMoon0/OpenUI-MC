# OpenUI MC 0.0.11

## UI behavior

- Make normal `Ui.text(...)` body text wrap by default when width-constrained and grow to its measured multi-line height.
- Add `TextWidget.nowrap()` as the explicit opt-out for compact labels, with ellipsis and marquee remaining explicit single-line overflow policies.
- Isolate legacy overlay render planes far enough apart that Minecraft native item rendering from a lower modal cannot punch through a later dropdown, popover, or tooltip.

## Verification

- Add cross-version regressions for default text wrapping behavior.
- Add legacy overlay render-order/depth coverage that verifies later overlay planes remain above the +150 Z used by native item rendering.
