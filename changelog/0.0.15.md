# OpenUI MC 0.0.15

- Add complete native Forge 1.12.2 and Fabric 1.16.5 modules, retaining the existing Forge 1.16.5 implementation and Java 8 compatibility.
- Add shared Minecraft 26.2 UI implementation with Fabric and NeoForge loader builds on Java 25.
- Preserve reactive controls, layout, focus, overlays, pointer/drag ownership and native screen/container lifecycle across the legacy adapters.
- Add legacy physical-key normalization, native text-field resize/selection preservation, transform-aware clipping and exception-safe matrix/scissor restoration.
- Keep new mod containers discoverable on dedicated servers without initializing client UI classes.
- Add deterministic source generation, stale-class cleanup, Java 8 regressions and native artifact metadata/bytecode checks.

See `docs/REQUESTED_GENERATIONS.md` for exact toolchain pins, local dependency installation, and the distinction between compile/unit/package evidence and live runtime acceptance.

### Independent review fixes
- Share the complete 26.x UI implementation and tests directly instead of maintaining cloned generation trees. Native loaders and resource formats remain explicit.
- Preserve supplementary Unicode input, prevent native hotkeys leaking through text/modal ownership, and let native clipping transform rectangles before intersection.
- Add real native input/clipping regressions and fail-closed shared-source wiring checks.
